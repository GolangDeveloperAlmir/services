# Support / Поддержка

> **Language / Язык:** [English](#english) · [Русский](#russian)

<a id="english"></a>
## English

- Start with the [README](README.md) and the [documentation index](docs/index.md).
- For a reproducible defect, use the
  [bug report form](https://github.com/GolangDeveloperAlmir/services/issues/new?template=bug_report.yml).
- For a usage question, use the
  [question form](https://github.com/GolangDeveloperAlmir/services/issues/new?template=question.yml).
- For a proposed improvement, use the
  [feature request form](https://github.com/GolangDeveloperAlmir/services/issues/new?template=feature_request.yml).
- Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md);
  do not include sensitive details in public issues.

This is a community-supported project. Maintainers do not promise a response
time or service-level agreement. Do not post passwords, tokens, personal data,
or production information in public reports.
